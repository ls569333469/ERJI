# ERJI 首批工程搭建范围

2026-09-24。以 PRD v1.0 的9月24日修订稿为基线，先交付 M0 工程和 M1 小池数据路径。

- Next.js + TypeScript 浅色全宽页面；信号阶段、建议参与/试仓、市场、图表、来源、设置、通知与历史入口。
- FastAPI/Pydantic 为唯一业务接口；OpenAPI 生成 TypeScript 契约。
- PostgreSQL + SQLAlchemy/Alembic；真实行情、OI、来源健康、设置版本、任务/outbox 和事件基础表。
- 采集、后台任务、通知分角色运行。首批 BTC/ETH/SOL/HYPE 小池，只读 Binance、Hyperliquid、Aster 公共接口。
- Charting Library 固定采用版本；补齐本地资源、历史和当前柱 Datafeed。
- 未完成的策略与 TG 发送明确显示未启用；真实模式不注入演示买入信号。
- CMC Key 不复制；初期使用已有脱敏样本进行能力/字段测试，避免无必要重复消耗 credits。
- Linux Compose 与 Windows 本地启动脚本，依赖锁定，针对单位/缺口/期限和接口做验证。

原预览与研究资料保留。该批工程完成不等于 M2–M5 全部策略、Meme 可交易性和生产运行验收完成。
