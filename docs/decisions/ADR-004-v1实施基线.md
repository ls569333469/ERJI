# ADR-004：v1实施基线

日期2026-09-23；状态：需求采用，正式代码待实施。优先于旧ADR冲突结论。

1. 核心数据为Binance/Hyperliquid/Aster原生，CMC免费Key补美元广度和清算；8次实测成功，但数量/结算周期/全部批量能力未获得。
2. Next.js + FastAPI/worker + PostgreSQL模块化单体；TA-Lib基础指标；DB租约与outbox。首版无需Redis/Celery/Kafka。
3. TradingView固定已验证Charting Library32.1.0；后台计算信号，图表不执行Pine社区策略。
4. 四个参与模板，行动与行情阶段分开，技术独立可用；1H可试仓，4H确认可参与，超价不追。保护/撤销/箱底失守三条线各自保存。
5. 主市场以同金额滑点与深度选取，异常DEX独立提示；不默认取最负费率冒充全市场。
6. Campaign保留长期首报，Episode记录独立结构，Snapshot统一表格/图表/TG，规则版本不可静默改旧计划。
7. TG文本为P0，绑定目标后发送；长轮询默认，TTL和未知发送结果明确。文档阶段不发测试消息。

默认值、规则和验收以[PRD](../01_产品需求文档_v1.0.md)为唯一基线。旧v0.7页面继续作为合成设计参考。
