# ADR-002：测试 MVP 采用 Charting Library 32.1.0

- 日期：2026-09-23
- 状态：用户确认测试、交流用途；取代 ADR-001 中的图表主方案
- 决定：使用前序已验证的 GitHub Charting Library 32.1.0 固定提交作为本地 MVP 图表组件。
- 固定提交：`4338800674706e4cbd88e65b873cc08d557dfbf0`
- 用户确认范围：更新需求文档并提供可评审 HTML MVP，不是批准商业部署、账户访问或交易执行。

复用内置图表、技术指标菜单和绘图，接入自己的 Datafeed。后台持仓、链上指标和正式扫描仍由项目实现；所有事件保存市场和时间口径。Lightweight Charts 只保留为备选，不再是当前测试 MVP 主方案。

先用合成数据验证信息结构及交互，原生行情接入在后续独立验收。图表通过本机服务器加载；缓存仅包含已访问的固定版本资源，缺失资源从同一提交按需补齐。保持原文件，不改库源码、不移除原有署名。

不因该选择声称图表库属于开源、会员解锁版或附带 Pine 策略服务。关于供其他主体部署的授权未在本轮验证。
