## Q6的实际链路

`满足异动规则 → 检查共振分类背景 → 覆盖不足返回unknown → 观察仍可见 → 形成T2需求`。

只有现有共振条件成立得到`market_comovement`时，才进入相应抑制逻辑；已存在可见观察还保留可见性。它与买入区间、原生盘口、报价有效期的T3资格判断不同。产品里无须新增解释条款或“70%达标才可以买”的提示。

## 对原方案的补充要求

1. 同池预留若被采用，名额控制必须发生在数据库连接借用前，并保证补数不会绕过预留；分池若被采用，总预算必须核对所有进程，不能只看某一池的size。
2. 围栏拆阶段应验证同一backend的解锁、错误与取消路径；HTTP及补数持久化仍需防双执行。禁止为了短持有统计在请求未结束时归还带锁连接。
3. A的诊断应有界、按变化或聚合保存，不逐tick写库；否则会增加当前写库争用。应检验指标本身的额外CPU/提交开销。
4. 轻量补发布只复用实际已生成的不可变快照；不得重新评估策略、越过当前有效期或把旧candidate拼成新异动事件。
5. 既有2＋2分析名额、普通300s、重点60s、OI15m/≥5%、T1连续15s、入场/盘口90s和费用参考保持原口径。未证明容量瓶颈前不增加并发或扫描频率。
