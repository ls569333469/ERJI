## 三版都保留

- 现在怎么做：可以买入、可小仓提前买入、等待买入、计划已失效；具体条件紧邻动作。
- 买入区、第一目标、日线条件目标、周线条件目标、原计划保护。
- 1H / 4H / 1D / 1W 状态，周线未确认不写成全周期共振。
- OI / 流通市值、同窗数量 OI 变化、数据来源和缺项。Aster / Hyperliquid 仅作补充证据。
- 策略模板独立于历史案例，匹配同时列相似点、反证和缺项。不显示未经校准的概率或相似度百分比。
- 原计划冻结，首次目标达标和失效保留，重复更新不创建重复机会。
- 顶部仅信号中心、策略档案、运行记录；运行记录合并采集、健康与信号历史。

## K线预览的真实与演示边界

- K线使用本地 MOVR / NOM / RAVE / MYX 的 `4h.csv` 与 `daily.csv` 历史归档，不调用外部 API。
- 预览计算 EMA20/50、BB20/2、MACD12/26/9；全部可用历史预热后截取显示，预热不足和 OI 缺值断线。
- 成交柱明确为报价成交额 USDT，数量 OI 独立副图。归档缺基础量，不能计算事件 AVWAP，图层禁用并解释原因。
- 1H / 1W 未导入预览归档，按钮禁用；不套用4H图表充数。正式方案仍要求这两个周期的真实计算与绘图验收。
- 行动、买入区、目标、保护、OI占比、周期判断、匹配与时间轴均为布局演示，不是本轮运行策略产生的真实信号。
- 预览显示的 EMA、BB 等通用指标不等于策略结构已画出；示例计划区间不是后端结构识别结果。正式版按主策略专属锚点画线，缺同事件证据不画买卖点。远端日周目标留在图外，不把K线缩成细线。
- 斐波、事件 AVWAP、自动形态标记仍按最终方案开发验证，预览不把这些模块冒充为已实现。

## 选定后共用的后端任务

1. 统一来源、单位、时间、覆盖和缺项，冻结各策略参数与版本。
2. 共用指标计算，逐项验证 10 个价格入口、3 个 OI 路径、2 个位置辅助和1个退出模块。
3. 可执行性独立检查：参与区、保护、目标、扣费后盈亏比与时效。
4. 历史匹配独立运行，避免未来数据泄漏，样本不足明确降级。
5. 持久保存事件生命周期，目标首次达标、保护调整、退出追加记录。
6. 受控后台采集和异步快照；前端读取目标 P95 ≤ 2秒，不靠提高 API 频率换速度，不承诺全部上游请求2秒内完成。
7. 每个主价格策略同步交付专属绘图锚点；图表、列表、机会详情及事件追踪绑定同一快照，时间、精度、来源周期、标签避让、缺值与快速切换逐项验收。
