2026-09-29 · 对照25号方案v0.3 · **本地代码更新及验证，尚未部署生产。**

## 1. 这次实际改了什么

信号总览改为“建议买入、等待买入、风险提醒、历史信号”。只有已经产生结构事件或交易计划的资产进入列表；普通波动、方向未明的资产继续在后台扫描，不下载到信号页面。试仓与确认买入合并展示，行内仍分别说明“小仓买入”和“买入条件已确认”。没有通过规则的币不会为了填满推荐页而变成买入建议。

页面现在读取后台预生成的摘要表，服务器先去重、筛选、排序，再返回25条。翻页不运行技术分析或调用交易所；原来隐藏视图仍请求全市场观察数据的问题已修复。保留首报、具体箱体、买入区、保护价、日周目标、数量OI变化、OI/市值和参考费率。目标来自结构与条件，评分没有改成未经验证的上涨概率。

币安合格现货、USDT/USDC线性永续资产取消前200名限制。Alpha和钱包保留流通市值、流动性门槛；不以FDV替代流通市值。Aster、Hyperliquid仅补充已匹配主池资产的OI等证据，不以辅助所目录扩充主池。经过验证的同币只留一条当前主行；未经验证的同名币不强行合并。

## 2. 实际调度方式

| 数据或环节 | 已实现的调度 | 边界 |
|---|---|---|
| 币安主目录 | 30分钟重新核对，完整保存准入状态 | 无到期报价任务时也保存目录变化；采集失败保留最后成功记录 |
| 币安/Aster OI | 普通300秒、候选60秒、活动计划30秒到期；最多20市场一批 | 目标间隔受排队、来源预算影响，不承诺每币精确准点 |
| OI历史 | 币安首次回补300个5分钟点，约25小时；成功后持久标记，不每轮重拉 | 1D就是滚动24小时；无可比端点不计算变化率 |
| REST资源 | 所有采集进程共享4个请求槽；来源权重账本、429退避 | 币安响应权重头触及保守预算时等待；仍需在服务器核对同IP其他项目占用 |
| Hyperliquid | 默认perp dex批量60秒；候选activeAssetCtx订阅，最多15秒落库一次 | 不声称覆盖全部HIP-3；推送频率由上游决定 |
| K线 | 冷启动原生1H/4H/1D/1W；后续尾部增量及最近300根内部缺口回补 | 初始化300根；不是多年全历史回补。未满足指标历史要求时停用对应判断 |
| 技术扫描 | 闭合K线事件触发相关市场扫描，5分钟全池兜底 | 形成中K线与收盘确认分开；技术计算按数据与参数缓存 |
| 逐币决策 | 活动计划约3秒、其他候选约30秒重新到期，最多4个资产同时评估 | 一币慢不阻塞其他币等待整轮结束；新鲜度不足立即暂停新买入 |
| 盘口/报价 | 候选原生订阅，完整top20盘口快照复用；REST补偿 | 只代表可见top20。报价15秒、盘口10秒门槛保留 |
| 钱包池 | 发现5分钟；资产独立到期，每次最多2个池任务，受免费池API预算约束 | 已改增量K线；修正原1H时长55分钟错误。池参考价不是可执行DEX报价 |
| CMC | 背景6小时、活动/稳定币换算30分钟；账户额度15分钟核对 | 结合账户已用额度及本地新增消耗，至少留10% |
| ByKaranteli | 目录6小时、共享摘要10分钟、活动地图30分钟独立排队 | 账户剩余额度尚未核实，显示本地账本口径；地图有时间与覆盖限制 |
| 页面 | SSE变更1秒合并，断线15秒补偿，隐藏页面停轮询 | 本地计时到期自动移除可买状态；固定排序不冻结安全判断 |

REST四并发是整个ERJI同一数据库schema共享的采集限制，不等于每秒只能4次。钱包每次2个任务是免费接口更严格限额的例外。行情、OI、K线、决策和页面各用自己的时钟，不再等待所有来源结束一个“大轮次”。

## 3. 图表与指标

真实图表已验证EMA20/50、MACD、成交量、布林带、确认支撑阻力、箱体与突破门槛、首报、日周条件目标；新增可开关的确认枢轴锚定VWAP与Chandelier参考线。后台计算序列与前端图层同源。原始失效价、计划当前保护和指标参考线分开，不把可上下变化的参考线冒充只能收紧的计划保护。

锚定VWAP只在右侧确认K线已经出现后输出，采用K线典型价与标的数量成交量近似；缺数量成交量留空。Chandelier参考采用区间最高价减ATR倍数，当前使用ATR14；它是ERJI独立标准实现。

**社区11项仍完整保留在analysis-registry.json。** 已实现的是登记说明的标准方法与展示，不是TradingView原Pine脚本运行环境。Wyckoff、Dual-Phase、BYO Pattern等原策略及依赖未完成逐根对照、失败样本回放，继续保持研究状态，未用于发布买入建议。原脚本哈希不伪填；ERJI独立实现记录自身源码哈希。
