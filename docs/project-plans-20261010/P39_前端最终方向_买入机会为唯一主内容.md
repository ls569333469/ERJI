# P39前端方向更新：买入机会为唯一主内容

> 本文为此前讨论方向。最新方案已调整为“买入机会默认打开、市场观察为平级入口”，异动与我的观察合并；以 [P39_前端最终方案_版块合并与数据保留.md](P39_前端最终方案_版块合并与数据保留.md) 和 [最终 HTML 预览](P39_最终前端方案预览_买入机会与市场观察.html) 为准。原 A/B 预览保留作设计历史。

本次依据用户最终确认替代此前T1/T2/T3主导航设计。正式业务代码尚未修改。

首页只有“现在可以买什么”一个当前机会列表。A以现有表格为基础，便于横向比较；B用紧凑信号卡片，便于阅读买入理由、参与区、目标与保护。两版共享同一语义，不为早期或确认触发另设机会类别。

优化对象是版块和视觉组织，原主要数据完整保留在列表或信号面板：代币/市场，当前建议/策略/阶段/触发价格/所需与当前量比，现价/首报价/首报变化/首报时间，参与区/保护或估算保护/触发距离，第一/日线/周线目标区间/计划空间/盈亏比/空间基准价，1H/4H/1D/1W趋势，OI/流通市值比/市值/原生来源/OI更新年龄/精确时间/资金费率及结算周期和来源/OI 1D变化与缺口原因。保持现有八列的信息分组；B只将它们重排为三个完整数据版块，不藏主要数据。

日线同第一目标、目标尚未形成、保护仅为估算、OI缺历史或市值未关联等状态都需要明确保留。预览的字段与现有OpportunityRow保持对应，样本数值为虚构，生产接口未改。

早期试仓、分批、突破、回踩等均是单条信号中的买入策略。前端不再设置“可小额测试”独立栏目，后端trial/participate动作的触发与资格差异需要保留，并映射为有效买入信号中的策略与风险说明；不能借此放宽门槛。

异动与持续观察、信号回顾、市场查询、系统状态、设置均在“更多”中；T1/T2/T3放在辅助诊断，首页不要求用户理解后台过程。

空结果必须区分数据有效但无符合条件的机会、数据异常无法确认、原机会到期、搜索无匹配。旧机会到期后不能继续冒充当前建议；历史快照始终独立。

预览默认使用虚构买入样本以展示布局，顶部可切换四种场景。图表和所有数据均为设计演示，不代表真实可执行信号。没有API调用、设置写入、消息发送或交易执行。
