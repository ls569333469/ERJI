# 数据字段与统一接口 v0.6

2026-09-23 · 对齐[PRD v1.0](01_产品需求文档_v1.0.md)。这是实现契约，当前HTML不是这些服务的实现。旧详细字段保留在[历史v0.5](03_数据字段与统一接口_v0.5.md)，冲突处以本文与PRD为准。

## 类型、时间与身份

Decimal以string传输、数据库numeric保存。UTC时间；event_time是源事件时间、received_at是到达时间、known_at是系统当时可知时间，不互相覆盖。Asset、Instrument、Pool、Venue分别建模；同ticker不自动合并。

```text
Asset: asset_id, symbol, chain_contracts[], identity_status, identity_evidence[], known_at
Instrument: instrument_id, asset_id, venue_id, native_symbol, dex_namespace,
  market_type, contract_type, multiplier, native_unit, quote_asset,
  listed_at, delisted_at, spec_version, known_at
RawEvent: source_id, native_id, event_time, received_at, sequence?, raw_ref, sha256
FieldQuality: status, reason, source_time, received_at, expected_refresh_seconds,
  age_seconds, source_ref, comparable_set_id?
```

FieldQuality.status统一为fresh/stale/missing/unmapped/no_market_in_scope/coverage_changed/insufficient_history/conflict/invalid。partial为对象级汇总状态，具体字段必须列原因。零值须有有效来源，未知值为null+reason。没有OI只暂停依赖OI的解释，技术路径按自己的必需数据继续。

CMC funding默认vendor_current，不进入FundingWindow。只有实际settled记录才逐次累计；负费率空头支付项max(-r,0)，收入项max(r,0)，固定名义本金净成本-Σr。base_quantity未知不能从不明price强行补齐。数量恒定而价格上涨只改变名义USD。反向合约单独按规格处理。

## 跨市场聚合

```text
AggregateSnapshot: snapshot_id, asset_id, as_of, category,
  usd_included_instruments[], quantity_included_instruments[],
  excluded[{instrument_id,source_id,reason}], provider_versions[],
  market_set_hash, sum_usd, compatible_base_sum?,
  windows[{start,end,start_set_hash,end_set_hash,comparable,
    delta_quantity_pct?,delta_usd_pct?,quantity_effect_usd?,valuation_effect_usd?,reason}],
  circulating_cap?, supply_snapshot_id?, nominal_density?,
  percentiles[{window,baseline_start,baseline_end,n,coverage_hash,value?,reason}], quality
```

同instrument只选一个合格主版本，其他源留作核对；同源相同ID不同内容先隔离冲突组。供应商交易对ID先映射合约规格，不能仅按ticker相加。当前USD覆盖与数量变化覆盖分别展示。变化窗口任一端覆盖变更时暂停比较，不能把新纳入市场当新资金。

## Campaign、Episode、Plan和Snapshot

```text
Campaign: campaign_id, asset_id, reference_instrument_id,
  first_seen_at, first_seen_price, first_confirmed_at?, first_confirmed_price?,
  first_recommended_at?, first_recommended_price?, state, ended_at?, end_reason?
Episode: episode_id, campaign_id, instrument_id, strategy_id, structure_id,
  origin_timeframe, knowledge_cutoff, detected_at, bar_close_time,
  confirmed_at?, invalidated_at?, invalid_reason?, frozen_upper, frozen_lower,
  frozen_atr, frozen_buffer, config_version, rule_version, prior_episode_id?
Plan: plan_id, episode_id, execution_instrument_id, direction,
  entry_zone, trigger_rule, protection_rule, revoke_rule, structural_break_rule,
  targets_1d[], targets_1w[], measured_targets[], fee_assumptions,
  net_r?, risk_budget?, expires_at, revision, revision_reason?

  anchor_ids[], confirmed_at, prerequisites[], history_start,
  status(pending|tested|passed|failed|insufficient_history), known_at

  schema_version, config_version, rule_version, as_of,
  action_new, action_existing, reason_codes[], phase, aggregate_snapshot_id?,
  primary_funding?, venue_anomalies[], support[], counter[], missing[],
  source_refs[], quality, expires_at, next_review_at
```

action_new：participate/trial/wait_entry/do_not_chase/pause。action_existing：hold/reduce/exit/not_applicable。用户看到中文行动；这些枚举不等于真实订单。首报不可改，首报后涨幅同参考市场计算。退出优先，数据故障暂停新参与但不删除保护位；事件失效不可复活。

图层由snapshot生成：box/range、trigger_marker、entry_band、protection_line、revoke_line、structure_break_line、target_zone、observed_liquidation。每个overlay保存instrument_id、origin_timeframe、snapshot_id、时间锚点、价格锚点和style_key；切市场不搬原价位。

## 适配器与应用接口

```text
capabilities() -> SourceCapabilities
list_instruments() -> Instrument[]
fetch_klines(instrument, resolution, start, end) -> Candle[]
subscribe_trades / subscribe_order_book -> EventStream
fetch_open_interest / fetch_funding / fetch_mark_index -> normalized + raw_ref
fetch_liquidations -> LiquidationEvent[] | NotSupported
fetch_liquidation_aggregates -> LiquidationAggregate[] | NotSupported
health() -> SourceHealth
```

不支持的方法返回NotSupported，不能空列表假装支持但没有交易。CMC支持aggregation provider，不能因其无trades/depth影响原生adapter。应用REST/SSE清单以PRD §9.3为准；统一响应含schema_version/as_of/data_quality/source_refs，列表另含list_snapshot_id/cursor/sort_version。图层、列表、TG使用同snapshot_id。

```text
  schema_version, config_json, validated_budget, effective_at, actor_id, reason

  lease_owner?, lease_until?, dedupe_key

  retry_after?, sanitized_error_code?, uncertain_result, current_state_check

```

Outbox与事件同事务，destination+event+transition+plan_revision唯一。进程重启按租约恢复；发送前再验证订阅、TTL与当前行动。网络超时标unknown，不保证sendMessage端到端恰好一次。设置不保存凭证正文，导出和日志不含secret；正式TG发送需用户明确绑定目标。

采集节奏和参数以PRD §8登记表为唯一默认，废止旧稿CMC统一5–15分钟等假设；免费预算约束优先于刷新期望。


## 2026-09-24补充：1D（原24H）数量OI及阶段视图

```text
OiWindowChange: period(1H|4H|24H), display_label(1H|4H|1D), duration_seconds,
  window_start, window_end, start_sample_time, end_sample_time,
  start_base_quantity?, end_base_quantity?, delta_quantity_pct?,
  market_set_hash_start, market_set_hash_end, evidence_snapshot_id,
  baseline_kind, sample_count, quality, reason, raw_refs[]
PhaseTransition: episode_id, from_phase, to_phase, changed_at, reason,
  snapshot_id, rule_version
SignalList: view, list_snapshot_id, as_of, filters, sort_version,
  unique_asset_count, action_counts, groups[{phase_id,asset_count,cursor,rows}],
  membership_updates_pending, safety_overrides[]
```

本次1D就是原有24H窗口的显示名称，内部仍为24H/86400秒；不得新增closed_day序列或重复请求。数量按as_of与24小时前的兼容同集合样本计算，起点>0，缺失为null+reason；不能用美元/price反推数量。OI的1D随采样滚动，图表1D是日K，两者以字段说明区分。

phase_id枚举：anomaly_watch/structure_pending/early_trigger/structure_confirmed/trend_continuing/weakening/invalidated/ended。具体条件以PRD §4.3为准，phase与action_new、quality正交；数据暂停不等于weakening。按当前主plan/episode归组，同asset每阶段视图快照一行；旧失效事件留历史，不遮蔽新有效episode。

`GET /v1/signals`支持view=stages|recommended|trial|all|derivatives、phase、action、group_by=phase、list_snapshot_id；默认stages。recommended只收participate，trial只收trial且均需有效可执行。组内cursor绑定group+snapshot+sort，组计数为全量筛选后的去重资产数。跨视图count不可累加成总资产数。固定排序快照不冻结安全状态，失效/超价/过期通过safety_overrides即时移出建议列表；客户端据此更新计数并记录当前版本。

SignalSnapshot增加phase_id、phase_changed_at、phase_reason和oi_changes[]；图层/列表/TG共享evidence_snapshot_id及signal snapshot。阶段变化不创建新episode、不重置首报，也不单独触发重复推荐提醒。
