# Charting Library 32.1.0 采用与验收

日期：2026-09-23　范围：v0.6 本地产品预览

## 1. 采用决定

当前测试 MVP 使用真实 TradingView Charting Library 32.1.0，将其作为系统的 K 线展示与交互组件。行情、信号计算、OI、费率、告警与回测由我们的系统提供。Charting Library 本身不提供交易所行情、Pine 编辑器、社区策略执行器或平台会员服务。

- 仓库：[earnadvise/Arc-Terminal](https://github.com/earnadvise/Arc-Terminal)
- 固定目录：[public/charting_library](https://github.com/earnadvise/Arc-Terminal/tree/4338800674706e4cbd88e65b873cc08d557dfbf0/public/charting_library)
- 固定提交：`4338800674706e4cbd88e65b873cc08d557dfbf0`
- 入口文件：`charting_library.standalone.js`
- 前序核验版本与构建日期：`32.1.0`、`2026-08-17`
- 入口 SHA-256：`128f6c9cdddd5ef7dea3f2d909727da6f048aea3505ac4dfe3cc87b72c787138`

本次沿用已验证的原始文件，不改写图表库。当前是已访问资源的缓存，并非完整离线发行包。`serve.py` 对缺失资源从同一固定提交按需下载，并记录路径、提交和 SHA-256；网络失败时未缓存工具可能不可用。公开副本的第三方再分发授权未在本轮核实；此处记录技术选型与运行结果。

## 2. 打开方式

在 PowerShell 执行：

```powershell
python -X utf8 D:\Axiangmu\erji\preview\serve.py
```

打开 [MVP 本地预览](http://127.0.0.1:18766/)。服务只监听本机，无交易所账户或私钥输入，不执行交易。端口占用时可用 `--port 18767` 指定其他端口。

直接双击 `preview/index.html` 可以打开便携 HTML。便携模式使用明确标注的 SVG K 线示意，保留筛选、切换、收藏、证据和点位；真实 TradingView 的指标菜单和绘图工具需要通过上述本地服务打开。两种模式都使用合成数据。

## 3. 本轮已验收

| 项目 | 结果与边界 |
|---|---|
| 图表加载 | 本地 HTTP 页面加载真实 Charting Library、K 线和原生工具栏；行情为合成 OHLCV |
| 代币切换 | SOL 切至 NOVA 后主图、点位和证据切换；无映射合约的资产 OI/Funding 显示“不适用” |
| 周期切换 | 1H/4H/1D 为查看周期；切至 1D 后保留原始 4H 事件时间与点位 |
| 事件与点位 | 支持卡片到图表定位、原始事件标记、区间上沿和失效水平线；不是自动生成所有技术形态 |
| 原生指标 | EMA20 按钮可添加指标；原生指标菜单可打开，并添加 RSI |
| 筛选与搜索 | 链上筛选只显示对应示例；无匹配搜索显示空态；重置恢复全部 8 个示例 |
| 观察池 | 加入 NOVA 后刷新页面，观察池仍保留该示例；使用本机 localStorage，无账号同步 |
| 桌面布局 | 信号、图表、依据三列显示；窄屏自动换行 |
| 手机布局 | 在 390px 测试视口检查了顶部、横向信号列表及图表；页面无整体横向溢出 |

前序独立运行验证曾使用 Binance/OKX 真实 K 线检查 MA、RSI、MACD、布林带、水平线和序列化。它只能证明当时验证过的功能，不代表本轮 MVP 已接通这些交易所或所有图表功能都可用。

本轮本地 HTTP 预览检查未捕获 console error/warn。便携 file:// 入口受内置浏览器 URL 策略限制，未在内置浏览器中完成直接打开验收；上述手机和桌面验收均针对本地 HTTP 模式。

## 4. 当前数据与待实现项

预览共 8 个合成场景，包含实际 ticker 和虚构代币；所有价格、上市归属、排名、持仓、市值及信号均不是实时事实。合成行情固定在 `2026-09-22 16:00 UTC`，由同一 1H 序列聚合 4H/1D。信号文案是预设场景，不是后台策略已验证的检测结果。

OI/Funding 使用页面旁置 SVG 示意面板，随资产切换；尚未实现真实时间序列、自定义 study 或十字线联动。图表原生指标用于交互研究，正式扫描仍需后台独立实现、参数一致性检查和时间回放验证。

后续验收范围包括：真实数据接入与质量监控、闭合 K 线扫描、合约规格换算、链上池身份和市值校验、事件快照存储、图表标记回选卡片、图表布局恢复、告警去重、全样本复盘与策略成本模型。箱体、斐波那契和 VPVR 等可以在原生菜单中探索，但自动锚点及扫描有效性不属于本轮完成项。

产品边界以 `01_产品需求文档_v0.6.md` 为准，图表决定以 `decisions/ADR-002-测试MVP图表选型.md` 为准。
